# Karibu: Your Fellowship Finder

Karibu shows Rotaract and Rotary clubs meeting near you, with the next date, time and venue. It is maintained by the **Rotaract Club of Rubaga**.

- `index.html`: public page (location, day strip, list and map)
- `guide.html`: user guide
- `request.html`: "Add your club" form, emailed to info@rotaractrubaga.org
- `admin.html`: admin area (clubs, meetings, cancellations, Import from Excel)
- `assets/config.js`: Supabase project URL and public (anon) key

Built with plain HTML, CSS and JavaScript, hosted on GitHub Pages, with Supabase (PostgreSQL and logins) as the backend and OpenStreetMap maps.
